# IT Support Homelab

Project Overview

The objective of this lab was to design, build, and deploy a functional IT Support Homelab that simulates a real-world corporate IT environment.

The project was designed to provide practical, hands-on experience with the technologies, systems, and administrative tasks commonly encountered in an enterprise IT support environment.

Through this lab, I explored different aspects of IT infrastructure, system administration, network configuration, user management, and technical support, with the aim of developing practical skills applicable to real-world IT operations.

This repository documents the configurations, tasks performed, technical processes, and lessons learned throughout the project.
